# AA1.1 BombOS

Welcome to the BombOS repo, a CFGS exercise.

### Requirements

To run this app you need:

- Cmake
- Visual Studio Build Tools
- (Optional) bash

### How to compile

You need to inject the correct env vars to compile this project. The easiest way is to open a developer command prompt.

Once open, you can call the bash scripts found in the [Scripts](./scripts) folder.
